プライバシーポリシー

ai-streaming は、チャンネルの持ち主が自分の配信のためだけに使うツールです。

  • YouTube Data API を通じて、持ち主のチャンネルのライブ配信と、そのライブチャットのコメント（表示名と本文）を読み取ります。
  • 読み取ったコメントは、持ち主のパソコンの中で配信のキャラクターに渡すためだけに使います。外部に送ったり、販売したり、第三者と共有したりしません。
  • Googleの許可の情報は、持ち主のパソコンの中にだけ保存します。許可は Googleアカウントの設定 からいつでも取り消せます。

Privacy Policy

ai-streaming is a tool used only by the channel owner for their own live streams.

  • Through the YouTube Data API, it reads the owner's live broadcasts and their live chat messages (display names and text).
  • Chat messages are used only on the owner's computer to pass them to the stream's character. They are not sent elsewhere, sold, or shared with third parties.
  • Google authorization data is stored only on the owner's computer. Access can be revoked at any time from Google Account settings.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
