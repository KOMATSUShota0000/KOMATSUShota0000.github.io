「ゆな」のライブ配信のプライバシーポリシー

最終更新日：2026年11月14日

「ゆな」のライブ配信（以下「本配信」）は、AIが演じるキャラクター「ゆな」が、視聴者のコメントに声で返事をする、個人（ゆな配信の中の人）が運営するYouTubeのライブ配信です。本配信が、視聴者の情報をどう扱うかを説明します。

1. 取得する情報

YouTube Data API を通じて、本配信のライブチャットから、次の情報を読み取ります（読み取りのみで、コメントの投稿・削除・管理はしません）。

  • コメントの文章
  • コメントを書いた人の表示名と、チャンネルID
  • コメントの時刻

本配信の運営者のYouTubeアカウントへのアクセスは、運営者自身が許可したものです。視聴者のアカウントには、アクセスしません。

2. 使いみち

  • ゆなが、コメントに返事をするため
  • 荒らしや不適切なコメントを止めるための判定（返事に使わない、画面に出さない）のため
  • コメントの内容に合わせて、配信画面の背景（ゆなの部屋）の雰囲気を変えるため
  • 配信が正しく動いているかを、運営者が確認するため

コメントの文章は、配信画面に表示しません。ただし、ゆなの返事の中で、コメントの内容に触れることがあります。

3. 外部への送信

返事を作る会話AIと、声の合成は、運営者のパソコンの中で動いています。コメントを、外部のAIサービスに送ることはありません。YouTube からコメントを受け取る通信だけが、外部とのやりとりです。

4. 保存と削除

判定と動作の確認のため、コメントの文章・表示名・チャンネルID・時刻・ゆなの返事を、運営者のパソコンの記録に残します。記録は、30日を過ぎると、自動で削除します。

5. 第三者への提供

法令に基づく場合を除き、取得した情報を、第三者に提供・販売することはありません。

6. 削除の依頼

ご自身のコメントの記録の削除を希望される場合は、次の連絡先にご連絡ください。コメントの時刻やチャンネル名をお知らせいただければ、対応します。

連絡先：g58.sg.jqeu@gmail.com

7. YouTube API サービスについて

本配信は、YouTube API サービスを利用しています。本配信を利用することで、YouTube 利用規約 https://www.youtube.com/t/termsに同意したものとみなされます。Google のプライバシーの取り扱いは、Google プライバシー ポリシー https://policies.google.com/privacyをご覧ください。

運営者のYouTubeアカウントが本配信に与えたアクセス権は、Google のセキュリティ設定 https://security.google.com/settings/security/permissionsから、いつでも取り消せます。

本配信が Google API から受け取った情報の利用は、限定利用（Limited Use）の要件を含む、Google API サービスのユーザーデータに関するポリシーに従います。

Privacy Policy (English summary)

Last updated: 2026-11-14

"Yuna" is a live stream run by an individual (the channel owner, "ゆな配信の中の人"). An AI-generated character answers viewers' live chat comments by voice.

Information we read

Through the YouTube Data API we read, from the owner's own live streams, the live chat comment text, the author's display name and channel ID, and the time of the comment. The tool is read-only: it does not post, delete or moderate comments. It never accesses viewers' accounts.

How we use it

To let the character reply, to filter abusive comments, to change the mood of the stream's background according to comments, and for the owner to check that the stream works. Comment text is not shown on screen.

Where it is processed and stored

Replies and speech are generated on the owner's own computer; comments are not sent to external AI services. Comment text, display names, channel IDs, times and replies are kept in logs on the owner's computer and are automatically deleted after 30 days. We do not sell or share this information with third parties, except where required by law.

Deletion requests and contact

To request deletion of your comments, contact g58.sg.jqeu@gmail.com. The owner's Google authorization can be revoked at any time at Google Account permissions.

This service uses YouTube API Services; by using it you agree to the YouTube Terms of Service. Google's privacy policy: policies.google.com/privacy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
